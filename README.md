# Second Draft

Website for Second Draft: websites and apps, finished.

The whole site is one self-contained file, `index.html` (fonts, artwork and logo are embedded), so it can be hosted anywhere that serves static files.

## Contact form
The form posts to Web3Forms. To switch it on, create a free access key at web3forms.com and paste it into `WEB3FORMS_ACCESS_KEY` near the bottom of `index.html`.

## Editing
Edit `index.html` and push to `main`; the host redeploys automatically.
